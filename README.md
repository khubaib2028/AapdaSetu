\# AapdaSetu 🚨



AapdaSetu is an AI-powered multimodal disaster management platform designed to connect citizens with emergency response teams.



\## Features



\- 🚨 Emergency disaster reporting

\- 🎤 Voice-based emergency description

\- 📷 Photo upload for incident evidence

\- 📍 GPS-based location sharing

\- 🧠 Explainable risk assessment

\- 🔴 Automatic priority classification

\- 📦 Resource recommendations

\- 🗺️ Interactive disaster and safe-location map

\- 📢 Disaster alerts and warnings

\- 📊 Emergency response dashboard

\- 🏠 Recovery and damage reporting

\- 🔐 Authority dashboard authentication



\## Disaster Reporting



Citizens can submit emergency reports containing:



\- Disaster type

\- Description

\- Number of people affected

\- Injured, children and elderly people

\- Water level

\- Immediate needs

\- Photo evidence

\- GPS location



The system analyzes the report and generates a risk score from 0 to 100.



Reports are classified into:



\- \*\*CRITICAL\*\*

\- \*\*HIGH\*\*

\- \*\*MEDIUM\*\*

\- \*\*LOW\*\*



The system also provides an explainable reason for the assigned priority.
